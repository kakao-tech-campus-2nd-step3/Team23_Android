# 💬 8주차 코드리뷰 받고 싶은 부분

## 1️⃣ 테스트 코드 작성
이번 주차에 미뤄왔던 테스트 코드를 작성해보았는데, 특히나 뷰모델 관련한 테스트코드 작성이 까다로운 것 같습니다.
일단 도메인, 데이터 레이어에 대한 유닛 테스트만 진행했는데, 이후 테스트 케이스를 구성함에 있어 궁금한 점이 몇 가지 있습니다.

### 질문
1. 보통 뷰모델에서는 UseCase를 통해 리포지토리의 데이터를 불러오는 기능을 수행하는데, 이 경우엔 UseCase를 전부 Mocking 하는 방식으로 테스트를 진행하는 게 맞을까요?
2. UI 테스트 케이스는 어느 정도로 구성해야하는지 궁금합니다. 너무 많은 테스트를 작성하는건 좋지 않다는 말을 강의에서 들었는데, 정말 중요한 UI 요소에 대해서만 테스트 케이스를 작성하는게 좋을까요?

## 2️⃣ Gradle 파일 관리
멀티 모듈을 적용하면서 여러 Gradle을 관리하게 되는데, 각 Gradle마다 중복된 코드도 많고, 정보들이 분산되는 느낌도 있는 것 같습니다. Gradle 스크립트를 깔끔하게 관리할 수 있는 팁 같은게 있을까요?
